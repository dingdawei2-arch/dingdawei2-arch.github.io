English

SoleCue is a private local reminder for running shoes, hiking boots, commute shoes, rain boots, and kids shoes.

Add a pair, record mileage, last care date, care cycle, reminder lead, cleaning, waterproofing, insole, lace, and location notes, then keep the next task visible with local reminders and widgets.

SoleCue does not connect to sports accounts, read GPS, scan mileage automatically, recommend shopping, use cloud sync, show ads, run analytics, or include tracking SDKs.
